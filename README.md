# Толщина диска — обновления

Официальный канал выпусков локальной утилиты «Толщина диска» для точечного изменения подтверждённого параметра в экспорте БАЗИС-Раскрой.

Здесь размещаются только созданное приложение и подписанные сведения о версиях. Заказы, материалы, управляющие файлы пользователя, базы, лицензии и ключ подписи сюда не загружаются.

[Выпуски и загрузки](https://github.com/Nikita15313/blade-thickness-updates/releases/latest)

Приложение само показывает доступную новую версию и устанавливает её по кнопке «Обновить приложение». Учётная запись GitHub оператору не нужна. Обычная работа с файлами доступна без интернета.

Канал win-x64 — автономная сборка для современных Windows10/11 x64. Канал net48-anycpu — совместимая сборка для Windows7 SP1/10/11 с установленным .NET Framework4.8. Приложение запускается от обычного пользователя из папки с правом записи.
